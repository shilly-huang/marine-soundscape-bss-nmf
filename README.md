# Blind Source Separation in Complex Marine Soundscapes: An Unsupervised Two-Stage Clustering Based on Non-negative Matrix Factorization

- **Title**: Blind Source Separation in Complex Marine Soundscapes: An Unsupervised Two-Stage Clustering Based on Non-negative Matrix Factorization
- **Authors**: Bingjia Huang, Zhipeng Li, Xiaoping Wang
- **Method**: Two-stage coarse-to-fine clustering
- **Task**: Blind source separation for complex marine acoustic signals

This repository provides the implementation of our proposed unsupervised blind source separation algorithm:
1. NMF-based spectrogram decomposition for mixed marine audio signals
2. Two-stage coarse-to-fine clustering strategy
3. Evaluation metrics: SDR, SIR, SAR, Precision, Recall, F1-score, DQF
4. Support for marine soundscape data

If you use this code or dataset in your research, please cite our paper:
Bingjia Huang, Zhipeng Li, Xiaoping Wang. Blind Source Separation in Complex Marine Soundscapes: An Unsupervised Two-Stage Clustering Based on Non-negative Matrix Factorization. The Journal of the Acoustical Society of America, 2025.
